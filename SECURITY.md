# Security Policy

## Reporting a Vulnerability

The `det` team takes software security seriously. If you discover a vulnerability or security issue, please do **NOT** open a public issue on GitHub.

Instead, please report it privately:

1. **Email:** Send details to **Saurabh Rai** at [saurabhr2@gmail.com](mailto:saurabhr2@gmail.com).
2. **GitHub Private Advisory:** Submit a report via [GitHub Security Advisories](https://github.com/det-Labs/det/security/advisories/new).

### What to Include:
- A clear description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept (PoC) code to reproduce the issue.
- Operating system and Python version used.
- Any suggested fixes or mitigations.

### Response Timeline:
- **Initial Response:** Within 48 hours of receipt.
- **Triage & Status Update:** Within 5 business days.
- **Public Disclosure:** Coordinated disclosure after a patch has been verified and released.
