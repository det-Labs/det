Foundational Architecture

The Three Directives of `det`

Built from the ground up for modern data engineers who demand local simplicity without sacrificing enterprise-grade lakehouse capabilities.

1. Vectorized Performance

Direct in-memory SIMD analytical processing with DuckDB 2.0. Multithreaded joins and aggregations execute on CPU cores with zero cloud serialization overhead.

  • Apache Arrow columnar interchange
  • Automatic projection & predicate pushdown
  • Sub-second pipeline cold starts

2. Declarative Modularity

Define lineage cleanly using dbt-compatible {{ ref() }} and {{ source() }} macros. Models resolve automatically into a topological DAG.

  • Graph cycle detection & stage parallelism
  • Self-contained workspace isolation
  • dbt-style selectors (+model+)

3. Universal Extensibility

Connect to any data ecosystem effortlessly. Join AWS S3 Parquet with a Delta Lake table and write directly into Azure ADLS Gen2 or PostgreSQL in one SQL query.

  • 14+ built-in multi-tier connectors
  • Dynamic Python connector extensions
  • Dual interface: Headless CLI & Web IDE

    customer_id,
    COUNT(order_id) AS total_orders,
    SUM(net_amount) AS total_spend,
    MAX(order_timestamp) AS last_order_at
FROM {{ ref('stg_orders') }}
WHERE order_status != 'CANCELLED'
GROUP BY customer_id;

models/staging/stg_orders.sql Multi-Source Jinja Lineage Macro 
{{ config(materialized='view') }}

WITH raw_s3_feed AS (
    SELECT * FROM {{ source('aws_s3_landing') }}
),
postgres_metadata AS (
    SELECT * FROM {{ source('prod_postgres', 'customer_dim') }}
)
SELECT
    o.order_id,
    o.customer_id,
    c.country_code,
    o.net_amount,
    o.order_timestamp
FROM raw_s3_feed o
INNER JOIN postgres_metadata c 
  ON o.customer_id = c.id;
models/schema.yml Declarative Assertions & Non-Blocking Quarantine 
version: 2
models:
  - name: stg_orders
    description: "Staging orders with row quarantine enforcement."
    columns:
      - name: order_id
        tests:
          - not_null
          - unique

      - name: net_amount
        tests:
          - expression:
              expression: "net_amount >= 0.0"
              severity: quarantine  # Routes bad rows to _quarantine_stg_orders

      - name: order_status
        tests:
          - accepted_values:
              values: ['PENDING', 'COMPLETED', 'CANCELLED']
run_pipeline.py Headless CI/CD & Automation SDK 
from pathlib import Path
from det import Workspace

# 1. Open active workspace
ws = Workspace(Path("./my_pipeline"))

# 2. Benchmark catalog health & cloud connectivity
health = ws.test_catalog()
print("Catalog Status:", health)

# 3. Execute topological pipeline DAG
report = ws.run()
print(f"Executed {report.total_models} models in {report.duration_ms:.1f}ms")

# 4. Run data quality assertions with quarantine routing
test_suite = ws.test()
print(f"Tests Passed: {test_suite.passed}, Quarantined: {test_suite.quarantined}")

# 5. Compile static HTML documentation
docs_path = ws.generate_docs()
print("Documentation generated at:", docs_path)
